# Agent Documentation

Read only the guidance whose trigger matches the task:

- [Development workflow](development.md) — modifying source, dependencies, generated artifacts, verification, tests, or runtime behavior.
- [Roblox structure profile](../roblox/structure.md) — making placement, startup, lifecycle, source-of-truth, or structurally owned dependency decisions.
- [Verification guide](../../docs/verification.md) — preparing dependencies, selecting focused checks, interpreting reports, or running Studio verification.
- [Continuity workflow](continuity.md) — starting, revising, completing, or reporting a milestone and its evidence.
- [Progress format](progress-format.md) — recording current evidence and full milestone history.
- [Roblox tooling guide](../../tooling/roblox/README.md) — refreshing the vendored Roblox definitions used by analysis and linting.
- [Project documentation](../../docs/README.md) — finding active human-facing project documentation or maintaining the documentation set.

The active continuity sources are [execution](../execution.md), [visions](../visions.md), and the [progress state page](../progress.md), which links the latest completed milestone. Use the [execution template](../templates/execution.md) for a fresh move and the [visions template](../templates/visions.md) when deliberately revising desired product outcomes; templates contain no active project state.

The agent and project indexes define the active project guidance. Skill packages under `.agents/skills/` route independently through their `SKILL.md` files.
